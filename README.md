# Sri Lanka Tourist Arrival Prediction
## Problem

Sri Lanka's tourism industry experiences substantial seasonal variation and has been affected by major economic and global disruptions. Accurate prediction of future tourist arrivals can support tourism planning, resource allocation and policy decisions. However, tourist arrivals are influenced by historical tourism trends, source-market demand, economic conditions and exceptional events.

## Proposed solution

This project develops supervised machine-learning regression models to predict the following month's tourist arrivals to Sri Lanka. The models will use historical tourist arrivals, temporal features, major source-market arrival patterns, exchange-rate information and disruption-period indicators. Linear Regression and Random Forest Regression will be implemented and compared using appropriate regression evaluation metrics.
